# ACGS 2024 Alignment

This page maps AlleleIQ's automated criteria to the specific ACGS
(Association for Clinical Genomic Science) 2024 UK best-practice
guidance points they implement, for reviewers checking alignment against
the current national standard rather than the original 2015 ACMG/AMP
framework alone.

## Points of alignment implemented

| ACGS 2024 guidance point | AlleleIQ implementation |
|---|---|
| BA1/BS1 must be applied with population-specific consideration, not a single pooled frequency. | `population_frequency.py` evaluates every ancestry group independently against `coverage_gaps`; a high frequency observed only in an under-covered population never triggers BA1. |
| PM2 should generally be applied at **Supporting** strength, not Moderate, absent strong gene-disease-specific justification. | `PM2Criterion.default_strength = EvidenceStrength.SUPPORTING`. |
| PP3/BP4 computational evidence should use validated tool-specific thresholds (REVEL, SpliceAI) with tiered strength, not a single pass/fail cutoff. | `computational.py` implements the two-tier REVEL (0.70/0.90) and SpliceAI (0.20/0.50) thresholds for Supporting vs. Moderate strength. |
| PVS1 requires a structured decision tree considering gene mechanism, transcript position (last/penultimate exon), and NMD-escape potential — not a flat "LoF = PVS1" rule. | `lof.py` implements a simplified version of this tree: consequence type → established mechanism (gene-disease validity + gnomAD constraint) → exon position. See [ACMG Framework](../architecture/acmg-framework.md) for the explicit simplifications. |
| The evidence-point (Bayesian) framework (Tavtigian et al. 2020) is the recommended quantitative method for combining criteria. | `scoring/bayesian.py` implements this directly, keyed on applied strength. |

## Points of ACGS 2024 guidance not yet automated

ACGS 2024 guidance extends well beyond the six criteria AlleleIQ
automates — segregation analysis (PP1/BS4), de novo confirmation (PS2),
case-control data (PS4), mutational hotspot/functional domain context
(PM1), reputable-source-without-shared-data handling (PP5/BP6, now
largely deprecated in ACGS 2024 in favour of direct re-review), and
multifactorial likelihood-ratio combination for specific gene-disease
pairs (e.g. Bayesian segregation LR in hereditary cancer genes) are all
outside AlleleIQ's current automated scope. These require clinical
context, family data, or functional evidence with no automatable data
source, and are intentionally left for the reviewing Clinical Genetic
Scientist rather than approximated.

## A note on currency

ACGS guidance is revised periodically. AlleleIQ's threshold values
(REVEL/SpliceAI cutoffs, PM2 strength default, coverage thresholds) are
all configuration, not hardcoded constants (see `.env.example` and
`alleleiq.config.Settings`), specifically so they can be updated as
guidance evolves without a code change.
